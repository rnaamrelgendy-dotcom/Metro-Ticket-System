The aim of the website is to facilitate the purchasing process for a metro ticket online.


Models:
▫	Metro line:
	    line number
▫	Station:
	    name
	    metro line
	    order (to get the price of the ticket)
▫	Ticket:
	    from station
	    to station
	    User
	    ticket price
▫	User (Built-in):
	    username
	    email
	    password
	    role 
▫	Ticket price:
	    Range (subtraction of stations order)
	    range price




Authentication & Roles:
▫	Manager:
	  Station
	    Add
	    Update
	    Delete
	  Ticket price
	    Update
	  Lines
	    Add
	    Delete
	  Users
	    View
	    Filter
	    Search
	  Tickets
	    View all tickets

▫	Passengers:
	  Buy the tickets
	    Form:
            From: station
            To: station
            Price: .......
            Buy ticket
	 Tickets
	    View, filter, search and sort own ticke
